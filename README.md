# Join - Kanban Board

Dieses Projekt ist ein **Kanban-Management-Tool**, das in einem **4-Personen-Entwicklungsteam** erstellt wurde. Es dient der Organisation und Verwaltung von Aufgaben in einem Kanban-Workflow.  

Das Tool wurde von unserem Team auf der Grundlage der ursprünglichen Arbeit des Hauptcontributors entwickelt. Der ursprüngliche Code und die Basis des Projekts finden sich unter folgendem Repository:  
[Join - Hauptrepository von Jan2810](https://github.com/Jan2810/join)  

## Features  
- Aufgabenverwaltung mit Kategorien und Subtasks  
- Backend-Anbindung an Firebase  
- Benutzerfreundliche Oberfläche mit JavaScript, HTML und CSS (SCSS)  

## Technologien  
- **JavaScript** (47.4%)  
- **HTML** (27.6%)  
- **CSS** (25.0%)
